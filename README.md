# 三色！ハイパーマン

巨大ヒーロー「ハイパーマン」が赤・青・黄の3色にカラーチェンジして、怪獣や宇宙人と戦う格闘アクションゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。

| カラー | タイプ | 特徴 | 必殺技 |
|---|---|---|---|
| レッド | バランス | 3連コンボ | トライ・シュート |
| ブルー | コンボ | 素早い5連コンボ | ブルー・ラッシュ |
| イエロー | パワー | 一撃が重く、攻撃中は怯まない | イエロー・インパクト |

## 操作

- 移動：← →　ジャンプ：↑　ガード：↓
- パンチ：Z　キック：X　必殺技：C（SPゲージ満タン時）
- カラーチェンジ：1 / 2 / 3
- スタート：Enter

スマホでは画面下のボタンで操作できます。
